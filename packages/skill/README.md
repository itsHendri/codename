# codename-skill

A design-system skill for coding agents: sets a project up with variables on
one naming scheme — three layers, states on every colour, one inactive set,
a primary/secondary/tertiary hierarchy — that Codename reads natively.

In progress. What exists:

- `references/NAMING.md` — the scheme, and why each choice.
- `references/tokens.css` — a starting point on it, placeholder values.

To come: `SKILL.md`, the setup steps, the rules an agent follows when it uses
the variables, and a visual explainer of the layer model.
